Política de Privacidad

Última actualización: junio de 2026

1. Responsable del tratamiento

El responsable del tratamiento de los datos personales recogidos a través de este sitio web es:

  • Titular: Mauro Miralles
  • Sitio web: robotspiscina.es
  • Contacto: a través del formulario de contacto disponible en la web

2. Datos que recogemos

Este sitio web es un portal informativo y de afiliación. No recogemos datos personales de forma directa. Sin embargo, pueden recogerse datos de forma indirecta a través de:

Cookies y datos de navegación

A través de herramientas de análisis (Google Analytics) podemos recoger datos anónimos sobre el uso del sitio: páginas visitadas, tiempo de navegación, dispositivo utilizado y ubicación aproximada.

Enlaces de afiliado

Este sitio participa en el Programa de Afiliados de Amazon. Cuando haces clic en un enlace de afiliado y realizas una compra en Amazon, Amazon puede recoger datos según su propia política de privacidad, disponible en amazon.es.

3. Finalidad del tratamiento

Los datos recogidos de forma anónima a través de cookies se utilizan exclusivamente para:

  • Analizar el tráfico y mejorar el contenido del sitio
  • Medir el rendimiento de las páginas
  • Mejorar la experiencia del usuario

En ningún caso se utilizan para fines comerciales propios ni se ceden a terceros salvo a los proveedores de servicios indicados.

4. Base legal

El tratamiento de datos se basa en el interés legítimo del titular del sitio en analizar el rendimiento de la web, y en el consentimiento del usuario para el uso de cookies no esenciales, de acuerdo con el Reglamento General de Protección de Datos (RGPD) y la Ley Orgánica 3/2018 de Protección de Datos Personales (LOPDGDD).

5. Conservación de datos

Los datos de navegación recogidos de forma anónima a través de Google Analytics se conservan durante un máximo de 14 meses, conforme a la configuración estándar de dicha herramienta.

6. Tus derechos

De acuerdo con el RGPD, tienes derecho a:

  • Acceso: conocer qué datos tenemos sobre ti
  • Rectificación: corregir datos inexactos
  • Supresión: solicitar la eliminación de tus datos
  • Oposición: oponerte al tratamiento de tus datos
  • Portabilidad: recibir tus datos en formato estructurado

Para ejercer estos derechos, puedes contactarnos a través de la página de contacto de este sitio. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD).

7. Programa de afiliados de Amazon

RobotsPiscina.es es participante en el Programa de Afiliados de Amazon ES, un programa de publicidad para afiliados diseñado para ofrecer a sitios web un medio para obtener comisiones por publicidad, mediante la creación de enlaces a productos de Amazon.es.

Esto significa que si haces clic en un enlace de este sitio web y compras un producto en Amazon, recibiremos una pequeña comisión sin coste adicional para ti.
